Questions are answered live: measure-aware retrieval runs as described in the paper, and Google's Gemini then writes the answer from the retrieved sources in a single pass, instead of the paper's local Qwen3-14B with its separate answer checks, so answers can differ from the paper's. Each answer is labeled with the model that wrote it. When the live model is unavailable, the sample questions show answers precomputed with the local Qwen3-14B pipeline. Questions you ask are sent to the Soprano Lab server and to Google's Vertex AI.

The lyrics shown with answers are LLM-assisted transcriptions of the scores. Expert evidence is shown in English translation, with the Korean original available under each item; the few items without an up-to-date translation are shown in Korean.

Paper: “Soprano Lab: Measure-Aware Question Answering over Expert Vocal-Performance Annotations” (ISMIR 2026 Late-Breaking Demo).
